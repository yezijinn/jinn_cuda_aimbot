# 当前 UI 菜单布局备份

> **本文档为备份/参考快照，非行为权威。**  
> 产品行为（含热键数量、扳机逻辑、类别过滤规则）以 [docs/IMPLEMENTATION_SPEC.md](IMPLEMENTATION_SPEC.md) 为准。  
> 当前版本为三热键架构（`MAX_MOUSE_HOTKEYS = 3`），热键 4、5 已删除。  
> 维护者参考 [AGENTS.md](../AGENTS.md) §11。

> 记录时间：2026-07-23
>
> 用途：保存当前页面菜单顺序、页面分布和主要控件布局，作为 UI 恢复对照。
>
> 来源：`overlay/overlay.cpp`、`overlay/draw_capture.cpp`、`overlay/draw_ai.cpp`、`overlay/draw_mouse.cpp`、`overlay/draw_buttons.cpp`、`overlay/draw_overlay.cpp`、`overlay/draw_debug.cpp`。

## 1. 顶部菜单顺序

当前 `kOverlayTabs[]` 的顺序如下：

1. **画面捕获**
   - 分组：采集与 AI
   - 内容：模型路径、模型后端、画面捕获来源和采集参数。
2. **热键 1**
   - 分组：热键配置
   - 内容：第一个鼠标热键的局部配置。
3. **热键 2**
   - 分组：热键配置
   - 内容：第二个鼠标热键的局部配置。
4. **热键 3**
   - 分组：热键配置
   - 内容：第三个鼠标热键的局部配置。
5. **全局配置**
   - 内容：全局 AI、检测、游戏配置、鼠标辅助、按键绑定和界面显示设置。
6. **鼠标输入**
   - 内容：鼠标输出后端及其设备连接参数。
7. **调试工具**
   - 分组：监控工具
   - 内容：截图、捕获预览、数据采集和诊断信息。

## 2. 画面捕获页

入口：`draw_capture_and_model_settings()`。

页面按源码绘制顺序包含：

1. **画面捕获**
   - 捕获方式。
   - 窗口、显示器或虚拟摄像头来源选择。
   - 窗口过滤、显示器选择和刷新/应用操作。
   - 捕获边框、捕获光标等捕获选项。
   - UDP 输入地址、端口和启用设置（使用 UDP 时显示）。
2. **模型路径与后端**
   - 模型选择。
   - 推理后端选择。
   - 模型路径相关操作。
3. **采集与性能**
   - 检测分辨率。
   - 采集帧率。
   - 圆形视野。
   - 捕获预览相关设置。

## 3. 热键页

入口：`draw_hotkey_profile(slot)`，其中 `slot` 为 0、1、2。

三个热键页面使用相同布局，每个页面的参数是对应热键的局部值；未设置局部值时回退到全局值。

主要分区顺序：

1. **热键启用状态**
   - 激活/关闭当前热键。
   - 当前热键状态文本。
2. **鼠标热键绑定**
   - 绑定鼠标键。
   - 热键优先级。
3. **检测参数**
   - 置信度阈值。
   - NMS 阈值。
   - 最大检测数。
4. **瞄准与目标控制**
   - 自动瞄准。
   - 启用目标追踪。
   - 瞄准模式。
5. **瞄准偏移**
   - 瞄准点 X。
   - 瞄准点 Y。
6. **移动修正**
   - 最小速度倍率。
   - 最大速度倍率。
   - 吸附半径。
   - 近距半径。
   - 速度曲线指数。
   - 吸附加速倍数。
7. **预测与辅助**
   - 预测间隔。
   - kalman滤波开关。
   - kalman位置/速度过程噪声。
   - kalman测量噪声。
   - kalman速度阻尼。
   - kalman最大速度。
   - kalman预热帧数。
   - kalman检测延迟补偿及其子参数。
   - 预测位置数。
8. **简易压枪**
   - 当前热键是否启用压枪。
   - 压枪强度。
9. **动态范围**
   - 动态范围开关。
   - 动态范围缩小范围。
10. **轨迹预测与辅助功能**
    - 轨迹曲线。
    - 轨迹距离、强度、微扰和速度参数。
    - 相关预测辅助参数。
11. **目标类别排序与启用**
    - 当前热键可用类别子集。
    - 类别启用/关闭。
    - 类别拖动排序。
12. **自动扳机**
    - 启用此热键扳机。
    - 目标丢失时停火。
    - 扳机区域和自动扳机时序参数。
    - 扳机区域预览。

## 4. 全局配置页

入口：`draw_program_config_page()`，绘制顺序固定为：

1. **目标类别**
   - 程序级类别总开关。
   - 未启用类别不会进入锁定、瞄准或扳机。
2. **AI/检测全局设置**
   - 全局模型、置信度、NMS 和最大检测数相关设置。
   - 全局瞄准、追踪、瞄准模式和动态范围设置。
3. **鼠标配置页面**
   - 全局 FOV 范围 X/Y。
   - 全局恢复出厂。
   - 游戏配置。
   - 配置管理。
   - 以上内容由 `draw_mouse_profiles()` 绘制。
4. **鼠标辅助**
   - 简易压枪。
   - 自动射击及相关倍率。
   - 轨迹/WindMouse 等鼠标辅助设置。
5. **按键绑定**
   - 退出、暂停、重新加载配置和其他动作的按键绑定。
6. **界面显示**
   - 面板透明度。
   - UI 缩放。
   - 从捕获中隐藏面板。
   - 保存配置到文件。

## 5. 鼠标输入页

入口：`draw_mouse_input()`。

1. **输入设备**
   - 输入方式选择。
2. **Arduino/Teensy 串口配置**（按后端显示）
   - 串口。
   - 波特率。
   - 16 位鼠标。
   - 启用按键。
3. **RP2350 配置**
   - 端口、波特率、16 位鼠标和按键支持。
4. **GHUB 配置**
   - 版本状态。
   - GHUB 文档按钮。
5. **Teensy RawHID 配置**
   - 序列号、VID/PID 过滤。
   - 用途页、用途 ID、打开索引。
   - 数据包超时和重连间隔。
   - 保存并重连。
6. **RAZER 配置**
   - 连接状态和 DLL 提示。
7. **KmboxNet 配置**
   - IP、端口、UUID。
   - 保存并重连、设备重启、图像操作等按钮。
8. **KmboxA 配置**
   - PIDVID。
   - 保存并重连。
9. **Makcu 配置**
   - 端口。
   - 波特率。

## 6. 调试工具页

入口：`draw_debug()`。

1. **截图按钮**
   - 截图按键列表。
   - 添加/删除截图按键。
   - 截图延迟。
   - 详细控制台输出。
   - OpenCV 构建信息按钮。
2. **数据采集**
   - 游戏中采集数据。
   - 仅启用瞄准时采集。
   - 仅检测到目标时采集。
   - 每 N 帧保存。
   - JPEG 质量。
   - 输出目录。
3. **自动标注**
   - 写入 YOLO txt 标签。
   - 最低置信度。
   - 每个文件最大框数。
   - 类别过滤。
4. **采集状态**
   - 已观察帧数。
   - 保存尝试数。
   - 图片数量。
   - 标签文件数量。
   - 解析后的输出目录和状态。
   - 复制路径、重置采集计数按钮。
5. **捕获预览**
   - 显示预览窗口。
   - 调试画面缩放。
   - 检测框、类别和瞄准点预览。

## 7. UI 结构约定

- 页面顶部使用横向菜单，菜单顺序由 `kOverlayTabs[]` 决定。
- 设置项普遍使用左侧标签、右侧控件的设置行布局。
- 设置行悬停时显示 tooltip；输入框、滑条、下拉框、按钮和复选框在控件绘制后调用统一 tooltip 机制。
- 热键页面是局部配置页面，不应与全局配置页面混合为单一配置。
- 全局类别开关是程序级硬开关；热键类别启用是全局启用类别的子集。
- 热键类别排序决定跨类别目标优先级。
- 本文只记录布局和分布，不作为配置值或业务逻辑的唯一来源。
