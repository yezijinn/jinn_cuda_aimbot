## Background
将现有多个一级菜单重新划分为全局设置与热键局部设置。全局设置负责程序运行环境、模型和系统控制；每个热键拥有独立的一级菜单，菜单内的瞄准与鼠标行为参数只在该热键生效时使用。

## 一级菜单结构

一级菜单保留或调整为：

- 画面捕获
- 热键 1 至 热键 5，仅显示已创建的热键
- 游戏配置
- 热键绑定
- 设置面板
- 性能统计
- 调试工具

以下原一级菜单不再单独显示：

- 鼠标移动
- 轨迹预测
- 辅助功能
- 目标追踪
- AI 模型
- 输入设备

这些菜单中的内容按全局/局部职责迁移到“画面捕获”或具体“热键 N”菜单中。

## In scope
- 最多创建 5 个热键配置。
- 每创建一个热键，新增一个独立一级菜单，菜单名称依次为“热键 1”“热键 2”“热键 3”“热键 4”“热键 5”。
- 删除热键后，对应一级菜单立即消失，并删除该热键的全部局部配置。
- 每个热键一级菜单的第一行必须是鼠标热键绑定。
- 热键仅允许绑定鼠标左键、右键、中键、侧键 1、侧键 2。
- 同一鼠标键不能绑定到多个热键。
- 新建热键默认为“按住生效”模式。
- 每个热键支持“按住生效”和“按一下切换”两种模式。
- 每个热键拥有独立的瞄准、范围、检测、目标锁定、偏移、类别启用与优先级、鼠标移动、轨迹预测和辅助功能参数。
- 热键局部参数至少包括：瞄准、检测、目标锁定、瞄准偏移、动态范围、类别优先级、速度倍率、目标修正、轨迹曲线与微扰、kalman预测、轨迹预测、触发系统和辅助功能。
- 多个热键同时激活时，优先级最高的热键生效；优先级相同时按创建顺序选择。
- “热键绑定”一级菜单只保留三个全局功能：全局退出程序、全局暂停自瞄、全局打开程序面板。
- “画面捕获”一级菜单最前面显示模型文件和模型路径相关设置，方便快速修改模型路径。
- 屏幕捕获、模型文件/路径/后端、数据收集、瞄准范围视角 XY、游戏配置、输入设备、设置面板、性能统计和调试工具作为全局配置。
- “自瞄键、开枪键、瞄准镜”不再作为全局独立设置；旧配置需要兼容迁移。

## Out of scope
- 不允许键盘按键作为新增热键绑定。
- 不允许同一鼠标按键绑定到多个热键。
- 不支持多个热键局部参数合并。
- 不为每个热键复制全局模型文件或捕获生命周期。
- 不改变模型推理后端的全局生命周期。
- 不保留已删除热键的历史局部配置。
- 不在“热键绑定”中保留开枪键和瞄准镜的独立配置入口。

## Assumptions
- 热键一级菜单名称按创建槽位显示为“热键 N”，N 为 1 至 5；删除后不自动重命名其他已存在菜单，避免用户配置对象与菜单名称发生隐式变化，除非实现采用稳定槽位复用并在界面中明确显示。
- 每个热键配置包含稳定的创建序号，用于优先级相同时的确定性选择。
- “按住生效”状态由当前物理鼠标按键状态决定；“按一下切换”使用按下沿翻转激活状态。
- 没有激活热键时，热键局部瞄准和鼠标行为不生效，但全局捕获、模型加载、统计和调试线程可以继续运行。
- 旧版 `button_targeting` 配置迁移为第一个热键；旧版 `button_shoot` 和 `button_zoom` 仅用于兼容读取，不再提供独立 UI。
- 新建热键的局部参数从默认局部模板初始化，不与其他热键共享可变数组或对象。
- 模型路径设置只影响全局模型加载，不随热键切换。

## Solution
增加 `HotkeyProfile` 配置实体和最多 5 个实例。每个实例保存鼠标绑定、激活模式、优先级、创建序号和完整局部参数。一级菜单由当前有效热键槽位动态生成，一级菜单名称为“热键 N”。

每个“热键 N”菜单的第一行显示鼠标绑定，下面依次显示该热键的瞄准、范围、检测、锁定、偏移、类别优先、鼠标移动、轨迹预测和辅助功能设置。编辑一个热键的局部参数只修改该 profile，不修改其他 profile 或全局参数。

“画面捕获”菜单将模型文件、模型路径、模型后端和相关模型加载操作放在页面前部，随后显示捕获方式、显示器/窗口、分辨率和预览设置。模型资源仍为全局资源。

“热键绑定”菜单仅显示三个全局绑定：退出程序、暂停自瞄、打开程序面板。新增热键的鼠标绑定不在该菜单编辑，而在对应“热键 N”菜单的第一行编辑。

运行时每次按键轮询计算激活热键集合，从中选择优先级最高、再按创建序号最早的实例，生成只读的 `ActiveHotkeySnapshot`，供目标选择、触发系统、预测和鼠标控制使用。配置修改通过完整快照边界传递，运行线程不能读取半更新的局部配置。

## Edge cases & risks
| Category | Notes |
|---|---|
| 菜单数量 | 第 6 个热键不能创建，并显示达到 5 个上限。 |
| 菜单命名 | 菜单名称与创建槽位的对应关系必须稳定，删除和复用不能导致配置错位。 |
| 绑定冲突 | 同一鼠标键已被占用时拒绝绑定，不自动覆盖。 |
| 默认模式 | 新建热键必须默认按住生效。 |
| 同时激活 | 只选择一个生效热键，不合并参数；优先级相同按创建序号。 |
| 切换模式 | 删除或重载配置后清除旧切换状态，避免幽灵激活。 |
| 旧配置 | 首次加载迁移旧自瞄键；迁移过程幂等，不重复创建。 |
| 全局模型 | 模型路径和后端必须保持全局，不能因切换热键而改变。 |
| 菜单迁移 | 旧鼠标移动、轨迹预测、辅助功能和目标追踪入口消失后，原功能必须仍能在对应热键菜单访问。 |
| 运行时一致性 | 配置修改不能让检测线程、目标线程或鼠标线程看到部分更新，使用快照交换。 |

## Acceptance criteria
- AC-1：无热键时，界面不显示“热键 N”一级菜单；创建第 1 至第 5 个热键时分别显示对应的“热键 1”至“热键 5”一级菜单；创建第 6 个热键失败并显示上限提示。
- AC-2：每个“热键 N”一级菜单的第一行是鼠标热键绑定，选项仅包含左键、右键、中键、侧键 1、侧键 2。
- AC-3：两个热键尝试绑定同一个鼠标键时，第二次绑定被拒绝，原绑定不改变。
- AC-4：新建热键默认使用“按住生效”；按住绑定鼠标键时激活，松开后停用。
- AC-5：切换为“按一下切换”后，每次完整按下绑定鼠标键只翻转一次激活状态。
- AC-6：多个热键同时激活时，仅最高优先级的热键生效；优先级相同仅选择创建序号最早的热键。
- AC-7：修改热键 N 的瞄准、范围、检测、锁定、偏移、类别优先、鼠标移动、轨迹预测或辅助功能参数后，其他热键和全局参数不改变。
- AC-8：删除热键 N 并确认后，“热键 N”一级菜单消失，其局部配置不再被保存或重新加载。
- AC-9：一级菜单只保留画面捕获、已创建的热键菜单、游戏配置、热键绑定、设置面板、性能统计和调试工具；鼠标移动、轨迹预测、辅助功能、目标追踪和 AI 模型不再作为独立一级菜单。
- AC-10：热键绑定一级菜单只显示全局退出程序、全局暂停自瞄、全局打开程序面板三个功能，不显示自瞄键、开枪键和瞄准镜入口。
- AC-11：画面捕获一级菜单的前部显示模型文件、模型路径和模型后端设置，修改后仍能正常触发全局模型重载。
- AC-12：在热键配置或切换生效热键期间，检测、目标选择、触发系统、预测和鼠标控制不会读取部分更新的局部配置。
- AC-13：旧版配置首次加载后自动产生第一个热键 profile，重复加载不会创建重复 profile。
- AC-14：构建项目后，程序能够加载无热键、单热键和五热键配置并启动，不发生崩溃。

|---|---|---|---|
